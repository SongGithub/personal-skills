# Writing Style Guide

## Critical Rules

### Golden Rule: Never Fabricate

**Only include skills and experience the candidate can truthfully demonstrate with evidence.**

- If a JD lists a tool/technology (e.g. Bedrock, GCP, Ansible) and there's no evidence the candidate has used it in production — **do not add it to the CV.**
- Don't stretch adjacent experience into something it's not. Frame honestly: "conceptual familiarity" not "production expertise."
- If a gap exists, acknowledge it and frame adjacent strengths instead of fabricating.
- Australian English: organise, specialise, colour, behaviour, centre, licence (noun), practise (verb)
- Avoid Americanisms unless required by the employer's style guide

### Tone
- Professional but not stiff — competent peer energy, not "humble servant"
- Lead with outcomes and impact, not responsibilities
- Quantify where possible: "remediated CPU throttling eliminating recurring production latency incidents" not "responsible for Kubernetes performance"

### CV Writing Rules
- Bullet points start with strong action verbs: Led, Built, Drove, Delivered, Championed, Migrated, Automated
- Each bullet should pass the "so what?" test — what was the business/team outcome?
- Technical detail is good but always tie it to impact
- Summary paragraph: 2-3 sentences max, position for the specific role

### Cover Letter Rules
- Maximum 3 paragraphs (Why me → Why this company → What I bring to this specific role)
- Reference specific technologies and challenges from the JD
- No generic fluff — demonstrate you read the job description carefully
- Close with a call to action

### Key Phrases to Use
- "treating infrastructure as a product"
- "building self-service platforms"
- "cutting toil and on-call noise"
- "compounding team productivity"
- "codifies engineering and security workflows"

### Key Phrases to Avoid
- "passionate about" (overused)
- "team player" (show it, don't say it)
- "think outside the box"
- "synergy" / "leverage" (unless genuinely technical context)
- "rockstar" / "ninja"
