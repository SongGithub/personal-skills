# 第一性原理创业与求职法

用这个 skill 的时候,你是在帮一个人从零开始——不管是创业还是换工作——核心思路:拆掉「历来如此」的类比思维,回到物理级的事实,然后重建。

## 核心精神

这篇文章最值钱的一句话:

> 一份好工作,一个好头衔,一个稳定的收入……是别人搭好的台子借你站一会儿。真正属于自己的舞台,只能自己一砖一瓦搭出来。

类比思维是最大的敌人(大家都这么做,所以我也该这么做)。第一性原理是唯一的出路(什么是我确定知道是真的?)。

三样东西,严格按顺序:

## 流程

### 第一步:生存现金流

**目标:** 先活下来。房租不等你。

**怎么做:** 不要学习,不要规划,不要「等准备好了再说」。在身边找一个大家正在抱怨的小麻烦,用最低成本、最快速度,变成一个收钱的闭环。

**来自文章的案例:**
- 宿舍同学想聚会没地方 → 和室友租个房子办活动,几块钱门票,一晚上几百号人,房租全覆盖
- 快递驿站太远、没人帮忙遛狗、周末不知道干嘛 → 随便挑一个,这周末就出一个最简单的服务方案

**规则:**
- 目标不是大富大贵,是完成一次完整的验证: 找到需求 → 给出解法 → 拿到钱
- 哪怕只有几百块,但你完成了一次认知升级: 原来我不需要任何人给我机会,我自己就能创造价值
- 这个认知,比那几百块值一万倍

**对应到求职(第一性原理找工作):**
- 不要花几周「先提升再投」——饿着肚子提升你学不进去
- 找那些有即时痛苦的公司,今天就能解决的痛
- 不要只投简历,带一个小交付物去接触——一个分析、一个修复、一个提案
- 目标是: 在正式面试流程之前,先完成一次「价值证明」

---

### 第二步:白痴指数

**目标:** 找到一个智商税特别重的行业,从第一性原理拆了它。

**公式:**

```
白痴指数 = 最终售价 ÷ 原材料成本
```

**倍数越高,机会越大。**

倍数高说明: 这个行业信息差大、效率低、中间有大量不必要的环节——而且最关键的,里面的所有人不是故意坑你,是大家都习惯了这么做。整个系统捆在一起了。

**来自文章的案例:**
- 航天业: 火箭卖上亿,铝和钛原材料占成本2% → 指数 ≈ 50x
- 留学中介: 收费三五万,核心服务只有文书修改 → 指数 ≈ 10x
- 装修辅材: 天价报价,材料本身很便宜

**怎么做:**
1. 选一个你熟悉的行业
2. 追踪: 客户付了什么 → 核心价值实际上成本多少
3. 问自己: 这个环节里最核心、最不可替代的价值到底是什么?
4. 用更直接、更透明的方式,只提供这一个核心价值

文章里的关键洞察: 对手很难模仿你,不是因为你多厉害,而是因为他们已经困在「历来如此」的思维里了,出不来。

**对应到求职(第一性原理找工作):**
- 哪些岗位/公司实际上值那个工资?哪些是虚高的?
- 哪些公司的招聘流程充满了形式主义的步骤,掩盖了真正需要的核心能力?
- 跳过形式,直接提供他们缺的那个核心价值
- 写简历和求职信的时候,第一性原理: 对方的核心业务需求是什么?不是HR的checklist

---

### 第三步:长期目标的物理第一步

**目标:** 为你那个「听起来像做梦」的长期目标,今天迈出物理意义上的第一步。

**文章的金句:**

> 你永远不会准备好,你只有在行动中才能变强,不可能变强了再行动。

**伟大和平庸的分界线:** 空想家在等准备好了再开始;高手知道永远不会有「准备好了」的那一天。

马斯克决定降低太空成本之后的第一件事: 打开表格,从物理公式和原材料价格开始,拆解火箭到底值多少钱。不是商业计划书。不是融资路演。一个表格。

**规则:** 第一步必须是「物理的」——看得见摸得着的行动,不是「心理的」——不是看书、不是学习、不是思考。

**来自文章的案例:**
- 想写书 → 今晚新建一个文档,写下第一个角色的名字
- 想做品牌 → 现在打开网页查「商标怎么注册」
- 想改变家乡 → 现在点开微信,联系第一个你觉得能帮上忙的人

**对应到求职(第一性原理找工作):**
- 梦想的公司还没招人? 今天找到招聘负责人的邮箱,发一封cold outreach
- 想转行? 今天找到这个行业的三个人,约15分钟聊天
- 这一步是你最想推迟的那件事——因为太小了,太「冒昧」了——那件事就是正确的第一步

---

### 三样东西的关系

| 步骤 | 目的 | 时间尺度 |
|------|------|---------|
| 生存现金流 | 拿到呼吸权 + 相信自己能创造价值 | 几天 |
| 白痴指数 | 找到真杠杆 | 几周 |
| 物理第一步 | 给方向、给意义 | 几小时 |

大多数人把这个顺序搞反了: 他们先做梦(第三步),但没解决生存(第一步),所以压力一来就垮了。或者他们找了个「安全的」工作(第一步),但从来没拆过任何东西(第二步),所以永远被商品化。

## 核心问题(反复问自己和对方)

- 「我确定知道什么是**物理上**真的,而不是大家习惯性接受的?」
- 「如果我现在一分钱没有、一纸证书没有,到今天结束前,我能促成的一笔最小交换是什么?」
- 「这个想法是『什么都不是』,还是『历史上曾经什么都不是』?」
- 「我在用类比思维(大家都这么做),还是第一性原理(这件事的本质是什么)?」

## 与常规建议的对比

| 常规 | 第一性原理 |
|------|-----------|
| 先学技能再变现 | 马上找一个需要,马上解决,马上收钱 |
| 写商业计划书 | 完成一个微型闭环 |
| 颠覆整个行业 | 拆一个离谱高价的环节 |
| 等准备好再开始 | 今天做一件看得见摸得着的事 |
| 优化简历关键词 | 证明你能直接解决问题 |
| 通过招聘门户投递 | 直接找到有痛点的那个人 |

---

## 什么时候不用这个框架

- 对方已经有稳定收入,只想做增量改善 → 用常规方法就行
- 对方需要的是真正无法短期习得的硬技能(比如神经外科) → 但多数「硬技能没人教」的情况经不起第一性原理追问
- 行业确实是强监管、低门槛无法切入(医生、律师) → 但就算这些行业,边缘服务也存在机会
