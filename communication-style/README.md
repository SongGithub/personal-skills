# communication-style

A writing-style plugin: direct, plain-spoken Australian English for anything the assistant drafts — chat replies, emails, tickets, PR descriptions, documents.

## What it does

- **Australian English spelling** — optimise, prioritise, colour, behaviour
- **Conclusion first** — lead with the answer, then the detail
- **Plain and direct** — no preamble, hedging or corporate padding
- **Active voice** — verb-forward sentences rather than passive constructions

## Usage

Lives inside the `personal-skills` marketplace. Install with `/plugin install communication-style@personal-skills`.

Adjust the `SKILL.md` to match your own voice: it is a starting point, not a fixed house style.
